Acerca de la solución

Botón de pago de servicios PagoMisCuentas. Esta API permite a empresas de servicios enviar los datos de las deudas para accionar la funcionalidad de Botón de Pago de Servicios. Esta funcionalidad se podrá disponibilizar a través de sus sitios web o avisos de facturación por e-mails;  a fin de que sus usuarios abonen desde allí las deudas informadas. El pago se podrá realizar a través de un formulario de pago, tal cual se realiza en la operatoria actual del sitio de pagomiscuentas.com.

¿Cómo funciona?

¿Dónde accede el usuario? El usuario recibe  un correo  electrónico o  accede a su deuda  publicada en el  sitio web de la  empresa

En el sitio web de  la empresa o en el  correo electrónico  tendrá el botón de  pago

Los datos de la  deuda y el usuario  viajan de manera  segura a través de  un Token

El formulario de  pago contiene el  detalle de la deuda  a pagar

Pantalla de validación y confirmación:
Una vez ingresado los datos el usuario valida los datos ingresados y posteriormente obtendrá  un comprobante  con el detalle

Una vez realizado el pago la empresa recibirá un aviso de pago en línea
